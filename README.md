# Wedding Budget Planner · Wedding Cost Tracker

A single-file, offline-friendly wedding budget planner: budget items & vendors, payments (paid / scheduled / overdue), category allocations, guest list & RSVPs, a planning checklist, charts, and JSON/CSV backup. All data stays in the browser (localStorage).

## 🔗 Live demo

**<https://wedding-budget-planner.pages.dev/>**

Hosted on Cloudflare Pages (project `wedding-budget-planner`).

## Run locally

Open `index.html` in any browser — no build step, no dependencies.
